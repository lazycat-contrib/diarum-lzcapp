# Diarum (吾身) - 懒猫云应用

## 应用简介

吾身 (Diarum) - 取自「吾日三省吾身」，一款零负担、快记录、怡复盘的日记应用。

## 功能特性

- 📝 Markdown 支持
- 🖼️ 媒体上传
- 🔒 自托管
- 💾 PocketBase 后端
- 🔧 可配置数据目录

## 使用说明

安装后访问应用即可开始记录日记。首次使用需要在 `/_/` 路径创建管理员账户。

## 数据存储

- 数据目录: `/lzcapp/var/data`
- 包含 SQLite 数据库和上传的媒体文件
